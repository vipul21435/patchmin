# Changelog

## 0.1.0

- First version: unified-diff parsing into hunks, ddmin over hunks with an
  optional second pass over the change lines of each needed hunk, a
  content-hashed run cache, a git-worktree test oracle with timeouts, a
  rest-of-suite command and reruns that flag flaky outcomes, and the
  `patchmin` command line.
